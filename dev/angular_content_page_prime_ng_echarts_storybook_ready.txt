# Projet: Content Page (Angular) — composants réutilisables + Storybook

Ce document contient l'arborescence et les fichiers (TS / HTML / SCSS / Storybook) pour: une page de contenu composée de plusieurs composants réutilisables, utilisant PrimeNG pour la datatable et ngx-echarts / Apache ECharts pour les graphes. Tu peux copier-coller chaque fichier dans ton projet Angular.

---

## Dépendances (installer si pas déjà fait)

```bash
npm install primeng primeicons @angular/cdk
npm install ngx-echarts echarts --save
# pour storybook (si pas déjà installé)
npx sb init --type angular
```

Ajoute dans angular.json les styles de PrimeNG (ex. dans "styles"):

```json
"node_modules/primeicons/primeicons.css",
"node_modules/primeng/resources/themes/saga-blue/theme.css",
"node_modules/primeng/resources/primeng.min.css",
"src/styles.scss"
```

## Modules Angular à importer dans ton `AppModule` (ou un module dédié)

```ts
// app.module.ts (extrait)

  imports: [
    FormsModule,
    TableModule,
    PaginatorModule,

```

Notes: p-table utilise la recherche globale via `globalFilterFields`. Le champ `[(ngModel)]="globalFilter"` est pour l'UI — pour connecter le filtre à p-table sans lazy-loading, tu peux utiliser la propriété `globalFilterFields` et l'input `p-table`-level event, sinon implémenter `filterGlobal` via `p-table`'s API.

## Split ECharts component (Page 2)

### src/app/split-echarts/split-echarts.component.ts
```ts
import { Component, Input, OnInit } from '@angular/core';

@Component({
  selector: 'app-split-echarts',
  templateUrl: './split-echarts.component.html',
  styleUrls: ['./split-echarts.component.scss']
})
export class SplitEchartsComponent implements OnInit {
  @Input() chartData: any[] = [];

  chartOptions: any;

  ngOnInit(): void {
    const categories = this.chartData.map(d => d.name);
    const values = this.chartData.map((d, i) => Math.round(Math.random() * 100));

    this.chartOptions = {
      tooltip: { trigger: 'axis' },
      xAxis: { type: 'category', data: categories },
      yAxis: { type: 'value' },
      series: [
        { data: values, type: 'line', smooth: true }
      ]
    };
  }
}
```

## Conseils d'intégration / bonnes pratiques

- Découpe les composants dans un module `ContentModule` et exporte-les pour Storybook.
- Fais des composants `@Input()`-driven (comme ci-dessus) pour favoriser la réutilisabilité et le test via Storybook.
- Pour ECharts, utilise `ngx-echarts` et évite d'importer ECharts globalement si tu veux du lazy-loading.
- Pour la table, si tu dois gérer des milliers de lignes, active le `virtualScroll` ou passe en lazy loading côté serveur.
- Ajoute des `aria-*` et tests d'accessibilité pour les blocs navigables.
